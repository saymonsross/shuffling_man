# Режим сценариста

Читалка-редактор сценария в браузере. История идёт лентой сверху вниз в порядке игры: кадр сцены, под ним текст, который игрок читает на этом кадре. Текст правится прямо на странице и сразу записывается в `.rpy`.

## Запуск

- `tools/screenplay.cmd` — двойной клик; или `python tools/screenplay/server.py` из корня проекта.
- Нужен Python 3.9+, без сторонних пакетов. Сервер слушает только `127.0.0.1:8765` (занят — следующий свободный) и сам открывает вкладку.
- Параметры: `--port N`, `--no-browser`. Остановка — `Ctrl+C` или закрыть окно консоли.

## Что на странице

- **Лента.** Сцены — глобальные лейблы из папок глав (`0_prologue/` … `4_endings/`) в порядке цепочки `jump`, начиная с `label start`. Подсцены (`label .tv`) — разделители внутри сцены. Сцены, до которых цепочка не доходит, собраны в конце под пометкой «Вне цепочки». Лейблы, вызываемые через `call` (мини-игры), — карточки внутри сцены.
- **Кадры.** Подряд идущие `scene`/`show` собираются в один слайд: крупно — последний полноэкранный кадр (картинка от 1600×900), мелко — остальные образы. Образ находится по `image`-определению (рекурсивно, до первого файла) или по имени файла в `game/images/`. Клик по кадру — увеличение.
- **Текст.** Реплики персонажей — с именем и тире, мысли рассказчицы — без имени, выборы `menu` — плашками, титры `_("…")` — крупно. Музыка (`mplay`) — строкой «♪». Теги `{…}` и подстановки `[…]` приглушены.
- **Переключатели.** «Слайды» — кадры или компактный список образов; «Техничка» — паузы, условия, переходы, звуки; «EN» — английский перевод под строкой из `game/tl/english/`.
- **Оглавление** слева — сцены и подсцены, подсветка текущей, число слов.

## Правка

| Действие | Как |
|---|---|
| Править строку | клик по тексту; `Enter` — сохранить, `Shift+Enter` — перенос строки, `Esc` — отмена |
| Сменить говорящего | список «Говорит» под полем правки |
| Новая строка | `Ctrl+Enter` при правке, кнопка `+` у строки, «+ текст» на кадре, `+` у пункта выбора — первая строка ветки |
| Переставить реплики | `↑`/`↓` у строки — с соседней репликой того же уровня, без кадров между ними |
| Удалить реплику | `✕` у строки |
| Открыть место в VS Code | `⧉` у строки или ссылка `файл:строка` в шапке сцены |
| Отменить запись | `Ctrl+Z` вне поля ввода или кнопка «Отменить»; стек живёт, пока работает сервер |
| Поиск | `Ctrl+F`, `Enter`/`Shift+Enter` — следующее/предыдущее совпадение |

- Правится только строковый литерал: отступ, `with`, аргументы и всё остальное в строке остаются как были. Кодировка, BOM и концы строк файла сохраняются.
- Каждая запись проверяет, что строка в файле не изменилась с момента загрузки; иначе запись отклоняется и страница перечитывается. Правки, сделанные в VS Code, подхватываются сами за 2 секунды.
- Запущенная игра с autoreload перезагружает скрипт после каждой записи.

## Порядок сцен

Сцены в оглавлении перетаскиваются; сцену можно бросить в «Вне цепочки» и обратно. Новый порядок сначала виден только на странице. «Предпросмотр» показывает, какие `jump` в концах сцен изменятся, «Применить к файлам» записывает их одним шагом отмены.

- Переход сцены — последний `jump`/`return` на верхнем уровне её тела. Он переписывается на следующую сцену; у новой последней сцены `jump` заменяется на `return` (выход в главное меню).
- Сцена без такого перехода получает `jump` после своей последней строки — предпросмотр об этом предупреждает: если сцена раньше уходит в главное меню, переход до игрока не дойдёт.
- Смена первой сцены переписывает `jump` в `label start` (`game/script.rpy`).
- Перестановка меняет только переходы. Состояние, которое сцена ждёт от предыдущих (флаги, музыка, `quick_menu`, эффекты), остаётся на совести автора — сцену стоит прогнать в игре.

## Ограничения

- Перевод привязан к тексту реплики: после правки русской строки её английский перевод теряет привязку («нет перевода» в режиме EN). Ren'Py создаёт новый блок при генерации переводов; старый остаётся в `game/tl/english/` и переносится вручную.
- Цепочка идёт только по безусловным переходам: сцена, которая выбирает продолжение через `if … jump`, обрывает ленту, а следующие за ней сцены попадают во «Вне цепочки».
- Реплики внутри Python-кода (`$ renpy.say`, экраны мини-игр) в ленте не видны.
- Сценарный текст принадлежит автору: инструмент — для правок человеком; агенты меняют реплики только по прямому запросу (правило `.agents/rules/scenario_text_immutable.md`).

## Устройство

- `server.py` — HTTP-сервер на стандартной библиотеке: модель сценария, картинки из `game/`, операции правки с проверкой строки и стеком отмены.
- `story_parser.py` — разбор `.rpy` построчно по отступам: лейблы, реплики, меню, `scene`/`show`, вызовы, переходы, определения образов, переводы. Модель строится заново на каждый запрос.
- `static/` — страница без сборки: `index.html`, `app.css`, `app.js`.
