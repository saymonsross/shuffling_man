# Path Tuner

Графический редактор spline-траекторий прямо в запущенной игре на Ren'Py —
аналог редактирования сплайна в Cinemachine. Кликами по сцене ставятся опорные
точки, кривая проходит через них; крайние ручки задают касательные на входе и
выходе. Призрак спрайта тут же проигрывает движение по кривой, а результат
копируется в буфер как готовый ATL с `knot`.

Позицию призрака считает та же интерполяция движка, что исполняет
ATL-сплайны, поэтому траектория превью и сгенерированного кода совпадает
точно — включая неравномерность скорости Catmull-Rom на неравных сегментах.

## Как устроена кривая

| Точек | Кривая | Ручки |
|---|---|---|
| 2 | кубическая Безье | ручки — контрольные точки Безье |
| 3+ | Catmull-Rom через все точки | ручки задают касательные старта и конца |

Ручка работает как безье-касательная своего крайнего сегмента: направление и
размах входа/выхода не меняются при добавлении точек. Внутренние касательные
Catmull-Rom считает сам и пересчитывает при каждой правке соседних точек.
Пока ручка не тронута, она стоит на трети крайнего сегмента — это классический
зеркальный фантом (`2·P0 − P1`), «естественный» вход кривой. Ручки закреплены
за своими крайними точками и переезжают вместе с ними.

Время делится между сегментами поровну, без выравнивания по длине дуги:
на коротком сегменте спрайт движется медленнее, на длинном — быстрее.
Призрак показывает это честно; равномерность достигается равными
расстояниями между точками.

## Режимы поворота

- **нет** — rotate в код не пишется;
- **фикс. значения** — линейно от стартового угла к конечному;
- **по касательной** — угол замеряется в опорных точках и сплайнируется
  между ними: это приближение к настоящей касательной, между точками углы
  могут слегка расходиться с ходом кривой (призрак показывает ровно то, что
  уйдёт в код). «Офсет» компенсирует базовую ориентацию картинки.

При любом rotate в код добавляется `transform_anchor True` — якорь служит
пивотом (правило rotate-transform-anchor).

## Работа

| Действие | Как |
|---|---|
| Открыть / закрыть | **F6**, ещё **Esc** на закрытие |
| Добавить точку | клик по пустому месту сцены (всегда в конец пути) |
| Двигать точку/ручку | тащить мышью |
| Точно двигать | **стрелки** ±1 px, **Shift+стрелки** ±10 px |
| Удалить точку | **Del** или кнопка |
| Пауза / играть | **Space**; на паузе скраб — баром на панели |
| Anchor (призрак и код) | **Tab** / **Shift+Tab** |
| Отменить / вернуть | **Ctrl+Z** / **Ctrl+Shift+Z** (или Ctrl+Y) |
| Копировать ATL-строки | **Ctrl+C** или кнопка |
| Копировать show-блок | **Ctrl+Shift+C** или кнопка |
| Убрать панель с дороги | **H**, кнопки «вправо»/«влево» |

Призраком служит выбранный в списке спрайт сцены (его же тег попадает в
`show`-блок) либо плейсхолдер 110×110.

### Что копируется

**Копировать ATL** — строки для вставки в существующий блок:

```
anchor (0.5, 1.0) pos (300, 850) transform_anchor True rotate -48.4
easein 2.0 pos (1500, 250) knot (-100, 1300) knot (700, 400) knot (1150, 650) knot (1850, -150) rotate -48.9 knot -83.7 knot -13.2 knot -10.5 knot -87.2
```

**Копировать show** — то же с заголовком `show <спрайт>:` и отступами.

## Ограничения

- **Камера.** Кривая и призрак рисуются в базовых координатах экрана и не
  повторяют `camera`-трансформы сцены. Числа при этом верные — именно их ждёт
  `pos`. Для точной картинки используйте песочницу (`dev_position_sandbox`).
- **Зум спрайта.** Призрак не наследует `zoom` спрайта из сцены — габариты
  могут отличаться, траектория и код от этого не зависят.
- **Точки добавляются только в конец пути**; вставки в середину нет —
  промежуточную точку проще дотащить с конца.
- **Отмена** покрывает точки и ручки; длительность, warper, поворот и anchor
  меняются кнопками без undo.
- **Запись в код.** Только буфер обмена: многострочный ATL-блок не
  переписывается на месте, в отличие от `placed(...)` у Position Tuner.

## Настройки

Все в начале `path_tuner.rpy`: `PATH_HOTKEY` (F6), шаги стрелок, радиус
захвата `PATH_HIT_R`, плотность отрисовки кривой, цвета, список warper'ов
`PATH_WARPER_ORDER`.

## Зависимости и тесты

Папка использует helpers Position Tuner (`pt_showing`, `_pt_num`,
`PT_ANCHORS`) — `position_tuner/` обязана лежать рядом. Состояние инструмента
живёт вне rollback и сейвов игрока. Инварианты сплайнов и smoke-тест экрана —
`game/dev/path_tuner_regression_tests.rpy`.
