# Озвучка пролога

Исходные дубли — файлы в корне папки, названные текстом реплики. Это исходники: в коде не используются, не удалять и не переписывать.

`work/` — обработанные копии, которые играет сцена: моно (каналы исходника идентичны), тишина в начале ужата до 0.03 с, в конце — до 0.25 с, общий для всех файлов подъём +15 дБ (самый громкий пик ≈ −3 dBFS; разница громкости между репликами сохранена), OGG Vorbis 48 kHz q6. Подключение — оператор `voice "prologue/work/<файл без .ogg>"` перед репликой в `game/0_prologue/prologue_scene.rpy`.
