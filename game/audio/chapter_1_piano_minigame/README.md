# Звук мини-игры пианино (глава 1, сцена 1)

Файлы читает `game/1_chapter/chapter_1_scene_1_minigame_piano.rpy` (`C1S1_PIANO_PARTS`);
ядро — `game/common/minigame_piano.rpy`. Аудио: OGG Vorbis, 48 kHz.

| Файл | Что это |
|---|---|
| `../keys/minigame_first_piano.mid` | эталон мелодии (`C1S1_PIANO_PARTS`): одна дорожка нот, любой темп (игра идёт в темпе метронома сцены), шаг — все ноты одной позиции (бас + мелодия), одновременные ноты одного имени — верхняя; октавы нот — из файла |
| `../keys/<нота><октава>.ogg` | сэмплы клавиш в `game/audio/keys/`: `c3.ogg` … `b5.ogg`, все 36 нот; имена строчные, диез — `#`. Нарезаны из записи `../keys/keys_set_c3-b5.ogg` (хроматика, удар каждые 5,647 с): нота от атаки (3 мс до порога 6 % пика) до 5 с или до 0,1 с перед следующим ударом, в конце — fade-out 0,1 с, пик нормализован к −4 dBFS (`TARGET_DB` в скрипте), `-c:a libvorbis -q:a 6`. Скрипт нарезки: `tools/cut_piano_keys.py`. В записи нет `g#3`, `a#3` и `e4` — они сделаны из `g3` (+1), `a3` (+1) и `f4` (−1) полутон через `rubberband` в ffmpeg. Октава имён — как в эталоне MIDI: `c3.ogg` = 65,4 Гц. Старые `*.mp3` той же папки в игре не звучат и звучат на октаву ниже нового набора |
| `../keys/soft/<нота>.ogg` | призвук промашки: 12 нот четвёртой октавы, 0.45 с с затуханием, на 14 dB тише клавиш; играет под `key_dead.ogg`, когда нажата не та клавиша (делает `tools/cut_piano_keys.py`) |
| `../keys/key_dead.ogg` | холостой «деревянный» щелчок неправильной клавиши (из `key_dead.mp3`, тот же пик) |
| `part_1.ogg`, `part_2.ogg`, `part_3.ogg` | записи партий; в игре не звучат — мелодия целиком из нажатий игрока |
| `wrong/1.ogg` | фальшь на предпоследнем шаге эталона (пик нормализован к −4 dBFS, как у клавиш): ноты шага не звучат, вместе с ней — стук в дверь (`sfx/c1s1/knock_door_1.ogg`) и обрушение нот |
| `wrong/2.ogg`, `wrong/3.ogg` | не используются |

Игровая клавиатура — одна октава: белые `z x c v b n m` (C…B), чёрные `s d g h j`; ввод по
физическим клавишам, раскладка не важна. Над клавишами ноты эталона опускаются в темпе
метронома сцены (`sfx/c1s1/metronome_loop.wav`, 85 BPM); текущий шаг ждёт у клавиш, пока не
нажаты все его клавиши, опоздание не наказывается. Отсутствующий файл не роняет игру —
пишется в лог.

Файлы, которые игра не использует (исходники и прежние варианты), вынесены из дистрибутива в `../shuffling_man_assets/audio_unused/` с теми же подпапками: `part_1.ogg`–`part_3.ogg`, `../keys/*.mp3`, `../keys/keys_set_c3-b5.ogg`.
