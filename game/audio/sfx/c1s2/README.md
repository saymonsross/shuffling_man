# Звуки сцены 2 главы 1

Файлы кладутся **сюда**: `game/audio/sfx/c1s2/`.
Формат: **OGG Vorbis**, 48 kHz, q5–q6, пик ≈ −3 dBFS, без тишины в начале
(атака в первых ~5 мс). Громкость выставляется кодом; путь внутри `audio/sfx`
пишется без расширения.

| Файл | Длит. | Что это | Где вызывается |
|---|---|---|---|
| `door_hover.ogg` | 0.37 с | короткий глухой щелчок открывающейся дверцы (Splice `ATMDoorOpen_S011IN.44.wav`, +7 dB) | наведение на проём спальни в КАДРЕ 1 (`c1s2_door_hover_zone`), створка приоткрывается |
| `c1s2_footsteps.ogg` | 2.75 с | шаги по коридору; пик −16 dBFS (тише нормы папки) | КАДР 1, перед репликой Вити «Доброе утро...»: шаги начинаются на паузе и заходят на реплику |
| `c1s2_female_crying.ogg` | 41.6 с | женский плач, по кругу | КАДР 4, с реплики «Трещина между нами росла...»: глохнет и обрастает эхом после «Я очень вас люблю...», обрывается с хвостом эха в КАДРЕ 6 |
| `c1s2_shakr_shark_shark.ogg` | 10.3 с | шарканье в темноте; пик −20 dBFS (тише нормы папки) | КАДР 6, на чёрном с головой после «...есть кто-то ещё.» |
