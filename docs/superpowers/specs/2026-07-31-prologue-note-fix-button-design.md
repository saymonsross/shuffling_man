# Пролог, сцена 1 — видимая кнопка «Поправить» вместо невидимых hover-зон

## Контекст

В `game/0_prologue/prologue_scene_1.rpy`, после реплики «Листы лежат криво. И
карандаш. Сначала нужно всё поправить — иначе не выйдет ни строчки.», игрок
сейчас выравнивает записку кликом по одной из двух **невидимых** хитзон —
экран `hover_click` (`game/common/interactions.rpy`) с попиксельным
`focus_mask` по бумаге и по карандашу. Автор хочет заменить это явной,
видимой кнопкой-подсказкой «Поправить», размещённой поверх записки.

## Решение

Заменить вызов `call screen hover_click([...])` на новый сценический экран
`prologue_note_fix()` в `prologue_scene_1.rpy`:

- Один `textbutton _("Поправить")` со своим лёгким стилем (без фоновой
  панели, размер по тексту — `choice_button`/`choice_button_text` не
  подходят: это полноширинный стиль экрана меню выбора реплик, 1185px с
  фоновой рамкой). Цвета берутся из существующих `gui`-переменных:
  `idle_color` — приглушённый `gui.choice_button_text_idle_color`
  (`#888888`), `hover_color` — акцентный `gui.accent_color` (`#cc0000`);
  шрифт/размер — `gui.text_font`/`gui.text_size`. Новых картинок не
  создаётся.
- Позиция — плейсхолдер-координата над запиской (между бумагой и
  карандашом), как и остальные `NOTE_*_POS` в файле; финально подбирается
  автором через Position Tuner (F9).
- `hovered`/`unhovered` кнопки по-прежнему пишут `note_hover_note` — значит
  подсветка предметов (`hover_lit` на `note_paper`/`note_pencil`) и
  перетекание руки в позу `move` (`flag_fade` по `NOTE_HOVER_FLAGS`)
  продолжают работать без изменений, просто триггерятся наведением на кнопку,
  а не на сами предметы.
- Клик → `Return("done")`, дальше сцена не меняется.
- Экран `modal True`; вызов остаётся обёрнут в
  `if not renpy.is_skipping():` (правило пропускаемых сцен — интерактив без
  развилки должен проходиться насквозь при пропуске).

`screen hover_click` в `game/common/interactions.rpy` после этой замены
останется без использований в проекте — по решению автора не удаляется,
остаётся как готовый переиспользуемый компонент для будущих сцен.

## Не меняется

- Сценарный текст — дословно как есть.
- Ассеты, `hover_lit`, `flag_fade`, анимация рук, переход в «ровное»
  состояние записки после клика.

## Проверка

1. Запустить сцену (`prologue_scene_1`), дойти до записки.
2. Навести на новую кнопку «Поправить» — убедиться, что бумага/карандаш
   подсвечиваются и правая рука перетекает в позу `move`, как раньше.
3. Кликнуть — записка выравнивается, сцена идёт дальше без изменений.
4. Проверить пропуск (Ctrl/«Пропуск») — сцена проходит без клика.
5. Подобрать позицию кнопки в игре через Position Tuner (F9).
