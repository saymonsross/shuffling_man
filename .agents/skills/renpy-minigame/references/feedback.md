# Отклик, эффекты, звук, доступность

## Образцы отклика

Единый язык наведения и отклика владелец ещё не утвердил (`docs/02_owner_review_2026_09_11.md`, «Предложенный
порядок работы», п. 3). Принятые образцы — замки (п. 06, 08) и уборка (п. 09); новую мини-игру строй по ним и
выноси отличия на согласование.

- **Наведение:** подсветка цели и звук. Если hover вычисляется непрерывно (tick, как в замках) или цели стоят
  вплотную, у звука антиповтор; hit-test один для наведения и захвата. Подсветку гаси при уходе, завершении, закрытии экрана и потере фокуса
  окна. Средства: `hover_lit(img, "условие", amount)` (ConditionSwitch, `game/common/interactions.rpy`),
  `At(img, brightness(…))`, контур `outline_hover` для мелких и тёмных деталей (`game/common/shaders.rpy`).
- **Запрещённое действие** в замках объясняется звуком отказа, лёгким движением, подсветкой нужной детали и текстом
  под объектом на короткое время; прогресс и захват не меняются; при reduced motion остаются текст и подсветка.
  В намеренно «немых» режимах (`docs/04_piano_minigame.md`) объяснений нет — это решение сцены.
- **Успех** держится на экране (выдержка или панель «Продолжить»), игрока не выбрасывает дальше без паузы;
  исчезновение цели — dissolve.

## Один импульс — весь «сок»

Удар, толчок, стук — это импульс в модели: сила `a` и время с момента удара `t`. Смещение считается аналитически
`a·exp(−t/τ)·sin(2πft)` и питает сразу тряску камеры, дрожь объектов и дребезг кнопки. Без накопления: результат
детерминирован, наведение и пересборка экрана его не перезапускают. Хит-зона кнопки неподвижна — трясётся только
визуал (`glow_button(..., visual_at=…)`).

## Что уже есть в проекте

Сначала `7dots-reference`, затем `game/common/`:

| Нужно | Готовое |
|---|---|
| Вспышка | `flash_fx(...)`/`flash_off()` — always-shown экран; no-op при «Без вспышек» |
| Сглаживание, параллакс, дрожь | `_fx_step`, `mouse_parallax`, `follow_camera`, `object_jitter_f`, зерно `fx_noise_strength` (`camera_fx.rpy`) |
| Кнопка-пятно | `use glow_button(label, action, …, pulse=…, visual_at=…)` |
| Размещение и движение | `placed` (с `transform_anchor`), `slide_in`, `move_between`, `flag_fade` (`transforms.rpy`) |
| Шейдеры | `sm.outline`, `sm.oval_glow`, `sm.noise`, `sm.crt_glass` |
| Переходы 7dots | `Flash`, `zpunch` — блокирующие `with`; внутри живой мини-игры не использовать |

## Звук (обёртки 7dots и пул проекта)

- В экране — только action-обёртки `SPlay`, `SFXPlay`, `SStop`: `splay`/`sm_sfx` возвращают handle, и не-None из
  action завершит экран, как `Return(handle)`.
- В коде — `sm_sfx(names, volume, tag, ext)`: отсутствующий файл пишет в лог один раз и не роняет сцену, звуки
  накладываются. Кортеж имён = случайный вариант через `renpy.random` — это контрольная точка отката на каждый
  вызов: варианты годятся для редких событий (действие, итог), не для частых тиков.
- `splay` накладывается, `sfxplay`/`mplay`/`vplay` заменяют свой слой; на линию 5 каналов — при пяти занятых лупах
  короткий звук пропадёт. Частые щелчки (деления диска, шаги) — одним тегом без наложения.
- Лупы удержания: handle в `default`, остановка по handle на выходе. Загрузка и откат восстанавливают лупы с начала,
  одиночные звуки — нет; игровое меню лупы не глушит.
- Луп, который следует за моделью (сердцебиение, дыхание), меняют по handle: `sm_audio_set_volume`,
  `sm_audio_set_filter`. Контракт пула — `docs/03_audio_system.md`.
- Короткие звуки во время пропуска играют, пока не включён `config.skip_sounds` (проект его не включает).
- Стилевые `hover_sound`/`activate_sound` идут мимо обёрток — не использовать.
- Звук из ATL `function` запрещён: по контракту `doc/transforms.html` её вправе звать в любой момент, в том числе
  при предсказании, и не один раз; зацикленный звук переживёт `scene`. Поэтому ATL-колбэки `sm_sfx_f` и 7dots
  `s_play`/`sfx_play` в мини-играх не используются: звук идёт из модели, тика и действий.

## Визуальные механики для хоррора

- **Фонарик / поиск в темноте.** Не полноэкранный лист с дырой в несколько экранов (лист 7dots — ~133 МБ кэша, больше
  лимита текстуры 4096). Темнота — шейдер на `Model()` размером с экран или `AlphaMask(Solid("#000"), маска,
  invert=True)` с маской, которую двигает function-трансформ; с 8.4 маску можно отдать шейдеру uniform-ом
  `u_mask "img"`. Луч точно под курсором делает «кликни, пока освещено» тривиальным для мыши: условие ограничивает
  только клавиатуру, геймпад и тач. Нужен поиск с усилием — дай лучу инерцию.
- **Линза правды / x-ray.** Слой «правды» под курсором; координаты — из `event()` CDD. Не пересобирать
  `Flatten`/`AlphaMask` в каждом кадре.
- **Глаза и надзор.** Зрачок меньше радужки и смещается сильнее — псевдо-3D поворот; направление — вектор от центра глаза.
- **Параллакс.** Проектный `mouse_parallax` + `_fx_step`. Хит-тест по сдвинутому слою учитывает его смещение.
- **Вспышка молнии как окно обзора.** Дешёвый дождь — несколько маленьких кадров с увеличением; вспышки — через
  `flash_fx`, с учётом «Без вспышек» (не чаще 3 в секунду).
- **Страх как визуал.** `matrixcolor` на `camera` (дёшево, переживает `scene`), виньетка и зерно шейдером по ОЗ.
- **Слои реальности.** Путь с подстановкой `"[reality]/room.png"` меняет весь набор картинок одной
  `default`-переменной.

## Шейдеры

- Регистрировать в `init -N`: `Transform(u_…)` в `define` падает сразу, если uniform ещё не зарегистрирован.
- Имена частей и переменных уникальны (все части собираются в одну `main()`); префикс `u__` раскрывается в имя шейдера.
- Цвет premultiplied: подмешивай `mix(px.rgb, c.rgb * px.a, k)`, иначе на прозрачных краях спрайта светится ореол.
- Своя цветовая часть — приоритет 300–399 (после выборки 200, до `matrixcolor` 400 и alpha 500).
- Каждый объявленный uniform задаётся трансформом, иначе ошибка при компиляции ATL.
- Пиксели внутри фигуры: у `Model()` без текстуры — `a_position`; у `Solid` с `mesh True` — `v_tex_coord` ×
  `u_model_size`. Сам `Solid` рисуется растянутой текстурой 10×10, и `a_position` у него — её координаты.
- `u_time` — только фаза циклов (по модулю 86400, float32); покадровый шум — `u_random`.
- GLSL ES 1.00 на web и мобилках; первая компиляция новой комбинации — фриз (кэш `game/cache/shaders.txt`).

## Производительность

- `renpy.restart_interaction()` пересчитывает все экраны и фокус — только на границах состояния.
- Function-трансформ с `return 0` крутит кадры, пока виден: вечные оверлеи с опросом мыши держат игру в постоянной отрисовке.
- Render-to-texture (`AlphaMask`, `Flatten`, `mesh`, `blur`) в каждом кадре дорог, на 4K-окне вчетверо.
- `DynamicDisplayable`, возвращающий новый `Text` на каждый вызов, пересобирает ребёнка каждый кадр — кэшируй.
- Детей CDD создавай в `__init__`, не в `render`; `renpy.get_image_bounds` рендерит при каждом вызове.
- Диагностика: F3 — оверлей производительности, `renpy.profile_screen(...)`.

## Доступность

- `sm_reduced_motion()` — движения нет: `sm_motion_scale()` и `sm_motion_time(t)` возвращают 0, а
  `sm_motion_transition(effect)` заменяет переход неподвижной паузой той же длительности
  (`game/common/accessibility.rpy`).
- `sm_flashes_disabled()` — без вспышек.
- **[проект]** `persistent.sm_simplified_locks` — пункт настроек «Простые мини-игры»: путь без таймера и без drag
  (кнопка шага с `default_focus`), проходимый клавиатурой, геймпадом и озвучкой. Флаг назван по замкам; общий
  хелпер вида `sm_simplified_minigames()` в `accessibility.rpy` предложи отдельной правкой.
- `alt` у картинок-кнопок, CDD и значимых картинок (`add … alt "…"`), инструкции — `group_alt`/`extra_alt`.
  Озвучка читает элемент в фокусе, а без фокуса — экран целиком (модальный — один): состояние, которое нужно
  услышать при игре кнопками, клади в `alt` фокусируемой кнопки.
- В 8.5 нет встроенного «reduce motion» — источник только проектные флаги. Моно-звук убивает подсказки панорамой,
  озвучка вдвое глушит остальной звук.
