# Ловушки: симптом → причина → исправление

## Цикл и интеракции

| Симптом | Причина | Исправление |
|---|---|---|
| Мини-игра сама закрывается через ~1,5 с или «проигрывается» при авточтении | цикл на голом `pause`: авточтение и пропуск его завершают | `call screen` + `Return`; ожидание ввода — только экраном |
| Колесо отматывает к началу мини-игры, лог отката пустеет | `while` + `renpy.pause(t)` не ставит контрольных точек, ~128 итераций вытесняют историю | модель A (контрольная точка на действие) или один `call screen` на серию |
| `show screen <modal>` + `pause 3` висит вечно | таймированная пауза держится под модальным экраном (`config.modal_blocks_pause`) | `renpy.pause(3, modal=False)` или `timer` в экране |
| Тик-модель замирает, когда поверх открыт свой модальный экран | `timer … modal True` молчит под модальным экраном | тот же тик-таймер в каждом модальном экране мини-игры |
| Наведение переключает реплику или закрывает экран | `hovered`/`timer`/`key`/`on` вернул не-None (например, handle звука) | такие action возвращают None; звук — `SPlay` |
| `Function(splay, …)` в экране закрывает `call screen` | обёртки звука возвращают handle | в экранах только `SPlay`/`SFXPlay`/`SStop` |
| «Cannot start an interaction in the middle of an interaction» | `renpy.pause`/`call_screen`/`input` из action или `event()` | вложенный диалог — `renpy.invoke_in_new_context(..., _clear_layers=False)` |
| Экран не обновляется, когда меняется модель | нет `restart_interaction` и представление не читает модель | рестарт на границах состояния или function-трансформ/CDD, читающие модель |
| Постоянные лаги, пересчёт всех экранов | `restart_interaction` на каждом тике, `timer 0.05 repeat True` + data-action | `Function(tick, _update_screens=False)`, рестарт только на смене фазы |
| «restart_interaction() was called 100 times…» / «Possible infinite loop» | побочный эффект при оценке экрана или цикл операторов без взаимодействия | экран без побочных эффектов; цикл с интеракцией в каждой итерации |
| `call screen X with dissolve` исчезает рывком | неявный `with None` после `call screen` | `call screen X(_with_none=False)` + свой `with` |
| Клики теряются сразу после каждого действия | блокирующий `with dissolve` после каждого клика | растворять только исчезающие цели |
| Мини-игра — тупик: нельзя выйти, или выход ведёт в главное меню | нет условия выхода; `return` из контекста `jump` | выход — часть контракта: условие → ожидание отпускания → `Return` → `return` в `call … from` |
| Каталог сцен после мини-игры выходит в главное меню | сцена кончается `return`, а не `jump` на следующую | сцены связаны цепочкой `jump`, мини-игра — `call … from`, навигатор — `full_restart(label=…)` |

## Состояние, сейв, откат

| Симптом | Причина | Исправление |
|---|---|---|
| Прогресс пропадает после загрузки посреди игры | загрузка возвращает к началу текущего оператора | контрольная точка на действие или осознанный «этап заново» |
| После отката или загрузки время скачет, `dt` отрицательный | метка часов в откатываемой модели | часы в `NoRollback`, `dt` с потолком, `last = None` при старте |
| `dt` тика скачет 15/31/47 мс, движение подрагивает | `time.monotonic()` под Windows с шагом 15,6 мс | `time.perf_counter()` |
| Загрузка сейва посреди мини-игры уводит в главное меню | мини-игра — первое действие после старта, до неё нет интерактивного оператора (наблюдение на 8.5.0) | перед мини-игрой хотя бы одна реплика или интеракция; учитывать в dev-входах |
| Прогресс не сохраняется и не откатывается | модель в `_fx_state`, в объекте из init или в `define` | модель только в `default` |
| После загрузки позиция логики и картинка расходятся | изменяемое состояние в `define` (краулер 7dots) | `default` |
| Лог отката засорён, откат «липкий» | `renpy.random` в покадровом визуале | свой `random.Random`; `renpy.random` — для редких игровых решений |
| Другая часть игры падает во время мини-игры | параметр лейбла `time=`/`range=` затенил модуль/builtin в store | префиксованные имена параметров; `import time as qte_time` |
| Исход переигрывается колесом мыши | политика отката не выбрана | выбрать явно ([architecture.md](architecture.md#сохранение-откат-пропуск-меню)) |
| Откатившись в пройденную игру, игрок заперт: ни назад к репликам, ни вперёд к итогу | безусловные `key "rollback"`/`"rollforward"` `NullAction()` действуют и в откате; `RollForward` лежит под экранами | `if renpy.roll_forward_info() is None: key "rollback" …`; `rollforward` не блокировать |
| После загрузки посреди раунда колесо уводит из мини-игры | блок колеса под `if not renpy.in_rollback()`: после загрузки оно истинно при первом показе экрана | `if renpy.roll_forward_info() is None:` |
| `Return()` дал `True`, а код ждал None | `Return()` без аргумента возвращает `True` | явные ключи результата |
| Поздний Ctrl вернул `True` вместо числа | `SkipOnce` из `sm_skippable_interaction` завершает интеракцию `True` | проверять `_return is True` отдельно |

## Ввод

| Симптом | Причина | Исправление |
|---|---|---|
| Колесо откатывает, Esc открывает меню при `modal True` | стандартный keymap живёт в underlay, модальность его не глушит | экранные `key … action NullAction()` для нужных привязок |
| Ctrl проскакивает мини-игру с исходом | пропуск обрабатывается до виджетов, `key "skip"` не работает | `skip_stop()`/`_skipping = False`; для пропускаемых — `is_skipping()`-обёртка |
| Кнопки мини-игры перестали нажиматься | блокирующий `key "dismiss"` объявлен после кнопок | блокирующие `key` — первыми в экране |
| Отпускание drag нажимает кнопку quick menu | mouseup дошёл до UI | `IgnoreEvent` после настоящего захвата, `zorder 110`, скрытие quick menu |
| «Вечный» drag после отпускания вне окна | SDL потерял mouseup | опрос `renpy.pygame.mouse.get_pressed()` с задержкой; сброс по `ACTIVEEVENT` |
| Подсветка или «зажатая» клавиша залипли после Alt+Tab | SDL оставил координаты, keyup не пришёл | сброс по `ACTIVEEVENT` с `gain == 0` |
| Буквенные клавиши не работают у части игроков | keysym сравнивает код клавиши текущей раскладки | стрелки, Space/Enter, цифры или `ev.scancode` в CDD |
| `keyup_dismiss` не срабатывает | префиксы не применяются к именам привязок | своя пара привязок press/`keyup_` |
| Геймпад: B открывает меню, LB откатывает посреди игры | стандартные `pad_bindings` | перехват конфликтующих `pad_*` в экране |
| Колбэк Drag падает с `TypeError` | Action в колбэке с аргументами | функции из `init python` / `renpy.partial` |
| `at` или `showif` внутри `draggroup` — исключение | в группе допустимы только `drag` | трансформ — на ребёнка `drag` |
| Детали Drag сбрасывают z-порядок и возвращаются в (0, 0) | lambda/меняющиеся аргументы пересоздают Drag | стабильные аргументы, функции уровня модуля |
| Вращение drag-ручкой «гуляет» | `rotate_pad` раздувает хит-зону Drag | вращение считать самому от пивота |
| Геймпад в QTE роняет игру | сырые события контроллера и неверная таблица кнопок (QTE_KEYPAD) | `pad_<control>_<state>` через `key`/`renpy.map_event` |

## CDD, трансформы, эффекты

| Симптом | Причина | Исправление |
|---|---|---|
| CDD досчитал итог, но `call screen` не завершается | итог выставлен в `render`, а `event()` не вызван | `renpy.timeout(0)` в `render`, возврат итога из `event()` |
| В CDD-игре не работают Esc, откат, F11, Shift+A | `IgnoreEvent` на все события | съедать только своё, остальное — `return None` |
| Таймеры других экранов останавливаются во время игры | CDD съедает `TIMEEVENT` | обрабатывать только события своих типов |
| Объект телепортируется после меню | `dt` из `st` без потолка | `min(dt, MAX_DT)` |
| Доля/счётчик выходит за предел на последнем шаге | последний шаг перескакивает конец раунда | `dt = min(dt, duration - t)` |
| Эффект или звук срабатывает дважды | побочный эффект в ATL `function`/`render`/`DynamicDisplayable` (предсказание, двойной вызов) | побочные эффекты — в тике или лейбле |
| Эффект дёргается при каждом клике | состояние в `trans.*` | `_fx_state` через `_fx_step` |
| Вздрагивание на стыках сцен | сброс накопителя по `st ≈ 0` | накопитель продолжает с сохранённого значения |
| Повёрнутая деталь уезжает с позиции | `rotate` + `anchor`/`pos` без `transform_anchor True` | `transform_anchor True`, якорь = пивот |
| Спрайт встал в долю экрана вместо пикселя | float в `pos` | `int(round(...))` |
| Анимированный шейдер «заикается» | нет источника перерисовки → 5 FPS | `pause 0` + `repeat` или `renpy.maximum_framerate` |
| `Transform(u_…)` в `define` падает | шейдер зарегистрирован позже | `renpy.register_shader` в `init -N` |
| Светлый ореол по краям спрайта с шейдером | подмешан непремультиплицированный цвет | `c.rgb * px.a` |
| Просадка кадров от фонарика или x-ray | гигантская текстура, пересборка масок каждый кадр | шейдер или маленькая маска; перерисовка только пока видно |
| Невидимые вспышки копятся | `renpy.show` без `hide` на master | `hide` или отдельный always-shown экран вспышек |

## Проверка и процесс

| Симптом | Причина | Исправление |
|---|---|---|
| Lint чистый, а экран падает при первом показе | lint не исполняет экраны и ввод | прогнать testsuite |
| `NameError` в lambda внутри теста | `python`-блок тест-кейса — `exec` с раздельными globals/locals | подмены — функцией в `init python` |
| Тест кликает в одно место, модель видит другое | курсор DSL не меняет `renpy.get_mouse_pos()` | подмена через `renpy.test.testmouse.get_mouse_pos` |
| «Проверено скриптом вне движка» | скрипт не видит экран, ввод, откат, сейв | testsuite в `game/dev/` и его прогон |
| Убран `window hide` «чтобы не выключить автоокно» | ложное убеждение: с 8.3 `window hide` автоуправление не выключает | `window auto False` — единственный выключатель |
| Вынос общего кода сломал готовую мини-игру | её файл правили без прогона её регрессионных тестов | выносить в `game/common/` отдельным шагом и прогонять тесты обеих мини-игр |
| Вторая копия каркаса молча подменила первую | одинаковые имена классов и функций в store | одно общее ядро жанра в `game/common/`, различия — параметрами |
| `global x` после использования имени работает, но присваивание не видно | Ren'Py молча поднимает `global`; присваивание до него локально | `global` первой строкой функции; лучше `store.x = …` |
