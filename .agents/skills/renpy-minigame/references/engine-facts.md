# Факты движка 8.5, расходящиеся с ожиданиями

Сверено по исходникам SDK 8.5.0; пункты «проверено прогоном» подтверждены тестами каркасов из `templates/` на 8.5.0.
Проект работает на 8.5.3, где эти пункты не перепроверялись: при расхождении верь 8.5.3 и поправь таблицы.

## Документация против кода

| Тема | Документация | Код 8.5 — верить ему |
|---|---|---|
| `BarValue.periodic` | «раз в начале интеракции» | на каждом рендере бара |
| Свойства экрана `modal`, `zorder` | «вычисляются один раз при старте» | при каждом создании экрана, параметры ещё не применены → только константы |
| `renpy.pause(t)` под модальным экраном | changelog 8.0.3: пауза завершается | держится (`config.modal_blocks_pause = True`) |
| Не-drag дети `draggroup` | разрешены | исключение «Only drags can be added to a drag group» |
| Порядок позиционных аргументов `Drag` | в `:args:` | другой → только именованные |
| Пример keysym `shift_mouse_1` | валиден | невалиден; правильно `shift_mouseup_1` |
| `register_channel(loop=None)` | «None → loop» | явный `None` не равен пропущенному параметру |
| `renpy.show(..., zorder=0)` | по умолчанию 0 | по умолчанию `None`, zorder сохраняется |
| `exclude` у экранного `input` | `"{}"` | фактически `None` → задавать явно |
| Озвучка на мобильных | не поддерживается | с 8.2.2 ограниченно поддерживается |
| Steam Deck | варианты `steam_deck`, `touch`, `medium` | `touch`/`medium` добавляются после `None` → экран с `variant "touch"` там не выбирается |
| Моно-звук | `force_mono`, `"toggles"` | `preferences.mono_audio`, `Preference("mono audio", "toggle")` |

## Изменения 8.x, которые бьют при переносе кода корпуса (демо писались под 8.1–8.4)

- **8.0** — `call screen` без roll forward по умолчанию (свойство экрана `roll_forward`); у drag `focus_mask = None`;
  `/` всегда float, а float в позиции — доля экрана.
- **8.0.3** — переделаны модальность, пауза и таймеры; у `timer` появилось `modal`.
- **8.1.2** — загрузка откатывает к оператору после последнего интерактивного, `$`-операторы между ними
  выполняются заново; ATL сравнивается глубоко и перезапускается при изменении используемых глобальных.
- **8.2.0** — data-actions `Cycle*`/`Increment*`; `DragGroup.add` кладёт деталь сверху (`config.drag_group_add_top`);
  B на геймпаде открывает меню, альтернативное действие — X; `renpy.get/set_screen_variable`; интерполяция `[…]` —
  выражения Python.
- **8.3.0** — `window show`/`window hide` не выключают автоуправление окном (выключает `window auto False`);
  префикс `anymod`; `Hide(immediately=)`; `keyboard_focus_insets`; текстовые шейдеры.
- **8.3.4** — `SpriteManager` сохраняется в сейвы (функции `update`/`event` — пиклуемые).
- **8.4.0** — остались только model-based рендереры; sampler2D-uniform в ATL (`u_mask "img"`); автооверсэмплинг
  ассетов `@2`; имена typing (`Callable`, `Any`, `Self`…) зарезервированы.
- **8.5.0** — `import renpy.pygame as pygame` (`pygame_sdl2` больше нет в store); метка `before_load`; тестовый
  оператор `drag`; у `screen` обязателен блок; `config.context_callbacks`.

## Ложные убеждения, встреченные на практике

| Убеждение | Как на самом деле |
|---|---|
| `window hide` без `window auto` выключает автоокно до конца игры | с 8.3 — нет |
| `modal True` глушит весь ввод | стандартный keymap (Esc, колесо, H, S, F, V, Shift+A) продолжает работать |
| Экранный `key "skip"` блокирует Ctrl | Ctrl обрабатывается до виджетов; нужен `_skipping`/`skip_stop()` |
| `K_a` не зависит от раскладки | код клавиши следует раскладке (под кириллицей не проверено) |
| `renpy.get_game_runtime()` годится для раунда | внутри одной интеракции не растёт |
| Таймер считает только видимое время | дедлайн разового `timer` хранится в `st` и срабатывает сразу после меню |
| Префикс `_` исключает переменную из сейва | сохраняются все имена, переприсвоенные после init |
| `renpy.retain_after_load()` в init-лейбле защищает прогресс | сбрасывается ближайшей жёсткой контрольной точкой |

## Проверено запуском на SDK 8.5.0

- `time.monotonic()` в Python 3.12.7 из SDK под Windows — `GetTickCount64`, шаг 15,625 мс; `time.perf_counter()` —
  `QueryPerformanceCounter`, 100 нс, тоже монотонный.
- `keysym "pad_…"` в тесте теряется без фокуса клавиатуры у окна; `renpy.queue_event("pad_…")` кладёт событие в
  очередь напрямую.

- `key [...]` со списком, где есть `pad_*`, срабатывает от `keysym "pad_dpleft_press"` в тесте.
- `key "dismiss" action NullAction()`, объявленный после кнопки, съедает её клик; объявленный до — нет.
- После `Rollback()` в пройденный `call screen` с `roll_forward True` прокрутка вперёд (`keysym "rollforward"`)
  возвращает прежний итог, если экран не блокирует `rollforward`; `run RollForward()` в тесте итог не вернул.
- `renpy.timeout(0)` в `render` + возврат из `event()` завершает `call screen` итогом CDD.
- До CDD доходят `renpy.map_event` со списками, `keyup_K_*`, `pad_*_release`, `ACTIVEEVENT`.
- Поздний пропуск через `sm_skippable_interaction` возвращает из `call screen` `True`.
- `run Rollback()` отменяет ровно одно действие модели A; сохранение в память и загрузка возвращают к её контрольной точке.
- После загрузки `renpy.in_rollback()` истинно при первом показе экрана (`after_rollback` сбрасывается уже после
  вычисления экранов), а `renpy.roll_forward_info()` — `None`; в пройденной игре после отката это прежний итог.
- `add … alt "…"` озвучивается, когда экран читается без фокуса; `id` у `add` со свойствами указывает на внутренний
  displayable, а не на обёртку, где лежит `alt`.
- В `python`-блоке тест-кейса замыкания не видят локальных имён.
