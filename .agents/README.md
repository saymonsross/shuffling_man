# Универсальный слой агентов

- `../AGENTS.md` — единая точка входа с инструкциями проекта.
- `skills/*/SKILL.md` — пакеты в переносимом формате Agent Skills; их discovery и проектная область применения задаются через `AGENTS.md` и при необходимости клиентские адаптеры.
- `rules/*.md` — проектное расширение, не отдельный межклиентский стандарт; область применения задаёт `paths` в YAML-frontmatter и описана в `AGENTS.md`.
- `plans/*.md` — исторические планы реализации, не активные инструкции.

У settings, permissions и UI-предпочтений нет общего межклиентского формата. Поэтому `.claude/settings*.json` остаются только compatibility-конфигурацией Claude и не являются источником проектных правил. Тонкие `.claude/skills` и `.claude/rules` возвращают нативное discovery Claude, но отправляют к каноническим файлам в `.agents`. Игнорируемый `.claude/settings.local.json` содержит персональные настройки разработчика и не переносится.

При изменении `name`/`description` skill или `paths` правила синхронно обновляй только соответствующий frontmatter Claude-адаптера; содержимое canonical-файла в adapter не копируй.
